คู่มือการใช้งาน · bot-fx

ดึงเรตอ้างอิง USD/THB ของ ธปท. ลง SQLite

bot-fx ดึงเรต Weighted-average Interbank Exchange Rate (THB/USD) รายวันจาก API ของธนาคารแห่งประเทศไทย ย้อนหลัง 20 วันทำการ แล้วบันทึกเป็นไฟล์ SQLite ไว้ใช้ทำรายงานหรือวิเคราะห์ต่อ ใช้คำสั่งเดียว รันซ้ำได้ไม่จำกัด

1

ภาพรวม

ทุกครั้งที่สั่ง uv run bot-fx โปรแกรมทำงานตามลำดับนี้

อ่าน API keyจากไฟล์ .env
→
ดึงข้อมูลเรียก API ของ ธปท. 2 ครั้ง ครอบคลุมราว 60 วัน
→
คัดข้อมูลตัดวันหยุดออก เลือก 20 วันทำการล่าสุด
→
บันทึกลงตาราง rates ในไฟล์ SQLite

เรตนี้เป็นเรตอ้างอิงรายวัน คำนวณจากรายการซื้อขาย USD ระหว่างธนาคารที่มูลค่าตั้งแต่ 1 ล้านดอลลาร์ เฉลี่ยถ่วงน้ำหนักด้วยปริมาณ ได้วันละหนึ่งตัวเลข เหมาะกับงานที่ต้องใช้ตัวเลขกลางเดียวกัน เช่น ตีมูลค่าสต็อกที่ถือเป็น USD ตอนสิ้นวัน งานบัญชี และรายงานผู้บริหาร ไม่ใช่ราคาซื้อขายหน้าเคาน์เตอร์ของธนาคาร

2

ก่อนเริ่ม

เตรียม 3 อย่างนี้ ใช้ได้ทั้ง Windows, macOS และ Linux

uvโปรแกรมจัดการ Python ไม่ต้องลง Python เอง uv โหลดเวอร์ชันที่ต้องใช้ให้
API key ของ ธปท.ขอฟรีจาก portal ใช้เวลารออนุมัติหลังส่งคำขอ
อินเทอร์เน็ตใช้ตอนติดตั้งและตอนดึงข้อมูล
3

ติดตั้งครั้งแรก

ทำครั้งเดียวต่อเครื่อง ใช้เวลาราว 10 นาที ไม่นับเวลารออนุมัติ API key

  1. 1

    ติดตั้ง uv

    Windows · PowerShell
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
    macOS / Linux · Terminal
    curl -LsSf https://astral.sh/uv/install.sh | sh

    ติดตั้งเสร็จแล้วปิดแล้วเปิด terminal ใหม่ แล้วเช็กด้วย uv --version ถ้าขึ้นเลขเวอร์ชันแสดงว่าพร้อม

    มี Python อยู่แล้ว?

    ติดตั้งด้วย pip install uv ก็ได้ ถ้าคำสั่ง uv หาไม่เจอ ให้ใช้ python -m uv แทนทุกที่ในคู่มือนี้

  2. 2

    ขอ API key จาก ธปท.

    1. เข้า portal.api.bot.or.th กด Sign up แล้วยืนยันอีเมล
    2. ไปที่ Catalogues → Exchange Rates → Access with this plan
    3. กดไอคอนตะกร้า → Create a new app → Submit Request
    4. เมื่อคำขอได้รับอนุมัติ ไปที่ Profile → My apps → เลือก app → Copy token
    เก็บ token เป็นความลับ

    อย่าแชร์หรือ commit ขึ้น git ไฟล์ .env ที่จะใส่ token ถูกตั้งไว้ให้ git ไม่สนใจแล้ว

  3. 3

    ดาวน์โหลดโปรเจกต์และใส่ token

    Windows · PowerShell
    git clone https://github.com/peerawet/mts-takehome-fx-rate.git
cd mts-takehome-fx-rate
Copy-Item .env.example .env
notepad .env
    macOS / Linux · Terminal
    git clone https://github.com/peerawet/mts-takehome-fx-rate.git
cd mts-takehome-fx-rate
cp .env.example .env
nano .env

    ในไฟล์ .env วาง token ต่อท้าย BOT_API_KEY= แล้วบันทึก

    .env
    BOT_API_KEY=token-ที่-copy-มา

    ไม่ต้องใส่คำว่า Bearer ไม่ต้องมีเครื่องหมายคำพูด และไม่ต้องเว้นวรรค

  4. 4

    ติดตั้ง dependency

    ทุกระบบ
    uv sync

    uv จะโหลด Python 3.12 และไลบรารีที่ต้องใช้มาไว้ในโฟลเดอร์ .venv ของโปรเจกต์ ไม่กระทบ Python อื่นในเครื่อง

ทุกระบบ
uv run bot-fx

ควรรันตอนไหน

ธปท. ประกาศเรตทุกวันทำการ 18:00 น. เวลาไทย ถ้าต้องการเรตของวันนี้ให้รันหลังเวลานั้น รันก่อน 18:00 ก็ได้ตามปกติ แถวล่าสุดจะเป็นวันทำการก่อนหน้า วันที่นับตามเวลาไทยเสมอ ไม่ว่าเครื่องจะตั้ง timezone อะไร

รันซ้ำได้ไม่จำกัด

ข้อมูลไม่ซ้ำ ทุกรอบอัปเดต 20 วันทำการล่าสุดและเพิ่มวันใหม่ แถวที่เก่ากว่านั้นยังเก็บไว้ ตารางจึงเริ่มที่ 20 แถวแล้วโตขึ้นวันละแถวเมื่อมีวันทำการใหม่ ถ้าหยุดรันไปหลายวัน รันครั้งถัดไปก็เติมวันที่ขาดให้เอง (ภายใน 20 วันทำการล่าสุด)

ถ้า ธปท. แก้เรตของวันที่บันทึกไว้แล้ว จะมีบรรทัด WARNING เพิ่มขึ้นก่อนบรรทัดสุดท้าย

WARNING Rate for 2026-11-20 changed: 33.953 -> 33.9999 (was fetched 2026-11-26T21:00:00+07:00)เรตวันที่ 20 พ.ย. ถูกแก้จาก 33.953 เป็น 33.9999 ตารางเก็บค่าใหม่แล้ว ค่าเดิมดูได้จากบรรทัดนี้ (ตัวเลขในตัวอย่างเป็นค่าสมมติ)
เห็น WARNING นี้แล้วควรทำอะไร

โปรแกรมทำงานสำเร็จตามปกติ ไม่ต้องรันใหม่ แต่ถ้าเคยนำเรตของวันนั้นไปใช้ในรายงานหรือการตีมูลค่าแล้ว ให้แจ้งผู้เกี่ยวข้องให้ปรับตาม ข้อความนี้แสดงแค่บนหน้าจอ ถ้าตั้งให้เครื่องรันเองโดยไม่มีคนดู ให้เก็บ output ลงไฟล์ด้วย uv run bot-fx >> bot-fx.log 2>&1 โปรแกรมตามแก้ได้เฉพาะวันที่ยังอยู่ใน 20 วันทำการล่าสุดของรอบนั้น

เปิดดูด้วยโปรแกรม

ใช้โปรแกรมอ่าน SQLite ทั่วไปได้ เช่น DB Browser for SQLite (ฟรี) เปิดไฟล์ .db แล้วไปที่แท็บ Browse Data หรือ Execute SQL

คำสั่ง SQL ที่ใช้บ่อย

SQL
-- เรตล่าสุด
SELECT period, rate FROM rates ORDER BY period DESC LIMIT 1;

-- ค่าเฉลี่ย 20 วันทำการ
SELECT ROUND(AVG(rate), 4) AS avg_20d
FROM (SELECT rate FROM rates ORDER BY period DESC LIMIT 20);

-- เทียบกับวันทำการก่อนหน้า
SELECT period, rate,
       ROUND(rate - LAG(rate) OVER (ORDER BY period), 4) AS change
FROM rates ORDER BY period DESC;

-- แสดงทศนิยม 7 ตำแหน่งแบบเดียวกับ API
SELECT period, printf('%.7f', rate) AS rate FROM rates ORDER BY period;

ส่งออกเป็น CSV เพื่อเปิดใน Excel

ทุกระบบ · รันในโฟลเดอร์โปรเจกต์
uv run python -c "import csv,sqlite3; c=sqlite3.connect('.venv/bot_api_daily_peerawet.db'); w=csv.writer(open('rates.csv','w',newline='',encoding='utf-8')); w.writerow(['period','rate','fetched_at']); w.writerows(c.execute('SELECT * FROM rates ORDER BY period'))"

ได้ไฟล์ rates.csv ในโฟลเดอร์โปรเจกต์ บรรทัดแรกเป็นหัวตาราง ตามด้วยหนึ่งบรรทัดต่อวัน (รันครั้งแรกได้ 21 บรรทัด และเพิ่มขึ้นตามวันทำการที่สะสม)

ตั้งค่าเพิ่มเติม

ตั้งในไฟล์ .env หรือเป็น environment variable ก็ได้

ตัวแปรค่า defaultใช้ทำอะไร
BOT_API_KEY(ต้องใส่)token จาก portal ของ ธปท.
BOT_DB_PATH.venv/bot_api_daily_peerawet.dbเปลี่ยนที่เก็บไฟล์ SQLite เช่น BOT_DB_PATH=data/rates.db โฟลเดอร์ที่ยังไม่มีจะถูกสร้างให้
ถ้าลบโฟลเดอร์ .venv ข้อมูลจะหายไปด้วย

ค่า default วางไฟล์ไว้ใน .venv ตามที่โจทย์กำหนด ถ้าจะใช้งานระยะยาวหรือมีคนลบ .venv เพื่อติดตั้งใหม่บ่อย แนะนำให้ตั้ง BOT_DB_PATH ไปที่โฟลเดอร์อื่น ข้อมูล 20 วันล่าสุดดึงใหม่ได้เสมอ แต่ข้อมูลที่เก่ากว่านั้นจะหายถ้าไฟล์ถูกลบ

8

คำถามที่พบบ่อย

ทำไมได้ 20 แถว แต่ช่วงวันที่กว้างเกือบ 4 สัปดาห์

ธปท. ประกาศเรตเฉพาะวันทำการ ไม่มีเสาร์อาทิตย์และวันหยุดราชการ 20 วันทำการจึงกินเวลาจริงราว 4 สัปดาห์ หรือนานกว่านั้นถ้ามีวันหยุดยาว

รันวันเสาร์อาทิตย์หรือวันหยุดได้ไหม

ได้ โปรแกรมดึง 20 วันทำการล่าสุดเสมอ วันหยุดไม่มีข้อมูลจึงไม่มีผลอะไร ข้อมูลที่ได้จะเหมือนกับรันวันทำการก่อนหน้า

ทำไมเรตไม่ตรงกับราคาที่ธนาคารประกาศหน้าเว็บ

เรตนี้คือเรตระหว่างธนาคาร (interbank) ไม่มีส่วนต่างซื้อขายที่ธนาคารคิดกับลูกค้า ราคารับซื้อหน้าเคาน์เตอร์จะต่ำกว่า และราคาขายจะสูงกว่าเรตนี้ ส่วนต่างราว 0.3 บาท เช่น วันที่ 26 พ.ย. 2026 เรตอ้างอิง 34.0140 ขณะที่ราคาเฉลี่ยของธนาคารพาณิชย์อยู่ที่รับซื้อ 33.8733 ขาย 34.2015

ถ้า ธปท. แก้ตัวเลขย้อนหลัง ข้อมูลในไฟล์จะเปลี่ยนตามไหม

เปลี่ยนตาม ถ้าวันที่นั้นยังอยู่ใน 20 วันทำการล่าสุดตอนที่รัน โปรแกรมเทียบกับค่าเดิมก่อนเขียนทับ ถ้าต่างจะพิมพ์ WARNING Rate for … changed: ค่าเดิม -> ค่าใหม่ ให้เห็น (ดูส่วนที่ 4) ส่วนวันที่เก่ากว่า 20 วันทำการจะคงค่าเดิมไว้ ปัจจุบันยังไม่มีหลักฐานว่า ธปท. เคยแก้เรตย้อนหลัง

อยากให้รันเองทุกวันต้องทำอย่างไร

โปรแกรมไม่ได้ตั้งเวลาให้เอง ใช้ตัวตั้งเวลาของเครื่องสั่ง uv run bot-fx ในโฟลเดอร์โปรเจกต์หลัง 18:00 น. ทุกวันได้ เช่น Task Scheduler บน Windows หรือ cron บน macOS/Linux

ใช้ API key เดียวกันดึงสกุลเงินอื่นได้ไหม

โปรแกรมนี้ดึงเฉพาะเรตอ้างอิง THB/USD ตามโจทย์ ธปท. มี API อีกตัว (Average Exchange Rate) ที่มี 19 สกุล แต่เป็นเรตที่ธนาคารซื้อขายกับลูกค้า คนละความหมายกับเรตนี้ รายละเอียดอยู่ใน observations.html
